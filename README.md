# Gut microbial strain-level genetic and functional diversity loss in the gut microbiome of westernized populations
This repository contains all scripts and analyses necessary to recreate the results reported in *"Gut microbial strain-level genetic and functional diversity loss in the gut microbiome of westernized populations"*.

Novel metagenomic samples from the TB-DAR cohort have been deposited and are available at the NCBI Sequence Read Archive (PRJNA1374062). Metagenomic-assembled genomes generated in this work are publicly available at http://cmprod1.cibio.unitn.it/resources/BlancoMiguezA_2026. All other data originates from publicly available sources, and is summarized in the supplementary materials associated with this manuscript.
